# Christopher Gonzalez — Résumé Site

Personal résumé and portfolio site for Christopher (Giovanie) Gonzalez.

## Contents

- `index.html` — single-file static site (HTML/CSS/JS, no build step, no dependencies besides Google Fonts).
- `assets/christopher-gonzalez-resume.pdf` — downloadable résumé PDF, linked from the site's "Résumé" buttons.

## Running locally

Open `index.html` directly in a browser, or serve the folder with any static file server:

```bash
python3 -m http.server 8000
```

## Deploying with GitHub Pages

1. Repo Settings → Pages
2. Source: Deploy from a branch → `main` → `/ (root)`
3. Save — the site will be published at `https://white-ovo.github.io/christopher-gonzalez-resume/`

Repo name is kept lowercase intentionally — GitHub Pages project URLs are case-sensitive.
